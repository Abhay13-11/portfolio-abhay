An ultra-modern, high-performance personal portfolio built for **Abhay Singh Chauhan**, Computer Science Engineering (Cyber Security) undergraduate at GL Bajaj Institute of Technology and Management.

Designed strictly with **zero generic AI blue dashboard elements** — delivering a full **3D Digital Cybernetic Developer Experience** featuring Three.js WebGL rendering, 3D interactive tilt cards, live terminal telemetry, and 100% verified data.

---

## ⚡ Key Highlights & Architecture

- **Hardware-Accelerated 3D Scene (`CyberScene3D.jsx`)**:
  - Interactive Three.js particle constellation shifting with cursor movement (`mousemove`).
  - Floating 3D holographic wireframe core (rotating icosahedron + orbital cyber rings).
  - Receding cybernetic ground matrix.
- **Interactive Terminal HUD (`TerminalHUD.jsx`)**:
  - Emulates an authentic developer command console right on the hero.
  - Interactive commands: `whoami`, `stats`, `projects`, `internships`, `contact`, `resume`, `matrix`, `clear`.
- **Command Palette (`CommandPalette.jsx`)**:
  - Quick-search modal toggled with `Ctrl + K` or `Cmd + K`.
  - Quick-copy for Email and Phone, jump to sections, and confetti trigger.
- **Synthesized Web Audio Feedback (`AudioController.jsx`)**:
  - Tactile cyber clicks synthesized dynamically using the native browser Web Audio API (zero audio file dependencies).
  - Includes a prominent mute/audio toggle switch in the navbar (default: muted for user privacy).
- **3D Card Perspective Tilt (`Card3D.jsx`)**:
  - Dynamic 3D hover tilt with custom specular glare reflection.

## 🚀 Getting Started

### 1. Run Locally
```bash
cd abhay-portfolio-3d
npm install
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 2. Build for Production
```bash
npm run build
```
Generates a minified, production-optimized bundle in `dist/`.

### 3. Deploying to Vercel
```bash
# Using Vercel CLI
npm install -g vercel
vercel
```
Or simply push this folder to your GitHub repo (`Abhay13-11/portfolio-website`) and connect it to [Vercel](https://vercel.com).
