## 🧭 Overview & Design Philosophy

This is the personal portfolio of **Abhay Singh Chauhan**, engineered with a strict design directive: **Zero generic AI blue dashboard templates**. 

Instead, this website is architected as an **immersive 3D Cybernetic Operating System** celebrating computational fundamentals, real-world systems engineering, verified credentials, and high-performance frontend interactions.

### ⚡ Architectural Highlights

- **Hardware-Accelerated 3D Scene (`CyberScene3D.jsx`)**:
  - Interactive **Three.js WebGL particle cloud** (1,200+ nodes) shifting dynamically with cursor movements (`mousemove`).
  - Rotating **3D holographic wireframe core** (icosahedron + glowing inner octahedron + counter-rotating orbital rings).
  - Receding cybernetic ground matrix grid with infinite parallax depth.
- **Interactive Terminal HUD (`TerminalHUD.jsx`)**:
  - Embedded developer command console directly in the hero section.
  - Interactive commands: `whoami`, `stats`, `projects`, `internships`, `contact`, `resume`, `matrix`, `clear`.
- **Command Palette (`CommandPalette.jsx`)**:
  - Quick-search modal toggled globally with `Ctrl + K` or `Cmd + K`.
  - Quick copy for Email and Phone, jump navigation, and cyber confetti trigger.
- **Synthesized Web Audio Feedback (`AudioController.jsx`)**:
  - Tactile high-tech click and chime sound effects synthesized on-the-fly via the browser's native **Web Audio API** (zero audio file dependencies).
  - Includes a prominent mute/audio toggle switch in the navbar (default: muted for user privacy).
- **3D Perspective Tilt Cards (`Card3D.jsx`)**:
  - Real-time 3D matrix transform reacting to cursor position with specular radial glare reflections.

## 💻 Local Development

### 1. Clone the repository
```bash
git clone https://github.com/Abhay13-11/portfolio-abhay.git
cd portfolio-abhay
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start development server
```bash
npm run dev
```
Open **[http://localhost:5173](http://localhost:5173)** in your browser.

### 4. Build for production
```bash
npm run build
```
Creates a minified, production-optimized bundle in the `dist/` directory.

All portfolio data (LeetCode stats, new projects, internship updates, contact info) is centralized in:
